  ## Task

  GitHub rate-limits anonymous API calls hard, so installs of
  GitHub-hosted tools in CI and Docker builds without a token fail every
  so often. The calls that matter here fetch a release and its assets.

  We run a shared versions host that caches this data. It serves a
  release at https://mise-versions.jdx.dev/api/github/repos/OWNER/REPO/
  releases/TAG as JSON in the same shape as GitHub's release object. TAG
  can be latest; the answer then carries whatever concrete tag the host
  currently considers latest, the same way GitHub's own /releases/latest
  never echoes back the literal word "latest". mise should use the host
  for public GitHub releases, including latest lookups.

  Signature and attestation verification is out of scope.
